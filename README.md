# Business Metrics Analyzer

Учебный проект по дисциплине «Проектирование и разработка бизнес-ориентированного программного обеспечения».

## Бизнес-задача
Расчёт и наглядная визуализация ключевых показателей эффективности (KPI) предприятия для оценки финансового состояния и принятия управленческих решений.

## Используемые технологии
- Python 3.10+
- pandas (для обработки и анализа табличных данных)
- matplotlib (для построения графиков)
- Git / GitHub (контроль версий)

## Инструкция по запуску
1. Клонируйте репозиторий: `git clone https://github.com/hefnerco/business-metrics-analyzer`
2. Перейдите в папку проекта: `cd business-metrics-analyzer`
3. Создайте виртуальное окружение: `python -m venv .venv`
4. Активируйте его (для Windows): `.venv\Scripts\activate`
5. Установите зависимости: `pip install -r requirements.txt`
6. Запустите приложение: `python main.py`

## Планируемые метрики
- Выручка по месяцам
- Рентабельность (Profitability)
